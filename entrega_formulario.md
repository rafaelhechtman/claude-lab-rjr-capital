# Formulário de entrega: o que preencher

O formulário é um **issue do GitHub** (modelo `entrega.yml` do repositório do case). É preciso estar logado no GitHub e preencher **uma única vez por time, até as 16h00**. O horário do envio fica registrado.

**Abrir o formulário:** https://github.com/jplucas29/claude-lab-financas-puc2026/issues/new?template=entrega.yml

## Campos, na ordem do formulário

| Campo | O que colocar |
|---|---|
| **Título do issue** | `[Entrega] RJR Capital — Case 3` |
| **Nome do time** (obrigatório) | `RJR Capital` |
| **Case** (obrigatório, lista) | `Case 3 — Comparativo de resultados` |
| **Integrantes** (obrigatório, um por linha, com nome, curso e período) | `[Nome 1] — [curso] — [período]` ... uma linha por pessoa (4 ou 5) |
| **Link do GitHub público do time** (obrigatório) | `https://github.com/[usuario]/[repositorio]` (preencher depois de criar o repositório) |
| **Link do artefato público** (obrigatório) | `https://claude.ai/artifact/VPjUz5QMzXdByXByLRVkga` (só vale depois de compartilhar o artefato como público) |
| **Link do vídeo** (obrigatório, até 2 min) | `[link do YouTube não listado ou do Drive com "qualquer pessoa com o link"]` |
| **Observações** (opcional) | Sugestão: `Apresentação em HTML (8 slides) com números do ITR e página em cada um; análises complementares com dados de fora do ITR estão no README do GitHub, marcadas como tal.` |

## Caixas de conferência (todas obrigatórias)

1. **Abri os três links numa aba anônima e todos estão públicos.** Faça isto de verdade: abra o GitHub, o artefato e o vídeo numa janela anônima.
2. **O README do GitHub do time segue o modelo e tem os links do vídeo e do artefato.** O `README.md` já segue o modelo; falta colar os links do vídeo e do artefato e preencher a equipe.
3. **Nenhuma senha, chave ou arquivo .env foi para o GitHub.** Nosso projeto não usa chave de API nem `.env`; confira mesmo assim antes de subir.

## Ordem sugerida para não travar

1. Compartilhar o artefato como público (claude.ai) e testar numa aba anônima.
2. Criar o repositório público no GitHub e subir os arquivos (lista no README do projeto).
3. Gravar o vídeo e subir como não listado (YouTube) ou "qualquer pessoa com o link" (Drive).
4. Colar os links do vídeo e do artefato no README e preencher a tabela da equipe.
5. Abrir os três links numa aba anônima.
6. Enviar o formulário (deixe uns 10 minutos de folga antes das 16h).
