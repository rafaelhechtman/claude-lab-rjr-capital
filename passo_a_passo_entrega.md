# Passo a passo da entrega (prazo: 16h00 de 06/11/2026)

Faça na ordem. Cada passo depende do anterior. Horários sugeridos a partir das 15h05; sobram ~13 minutos de folga. **O que não pode faltar: o formulário enviado antes das 16h, com os 3 links públicos.**

## Passo 1 · Tornar o artefato público (15h05 a 15h10)
1. Abra https://claude.ai/artifact/VPjUz5QMzXdByXByLRVkga
2. Use o botão **Compartilhar** (Share) e escolha a opção de **qualquer pessoa com o link / público**. Copie o link.
3. Abra uma **janela anônima** (Ctrl+Shift+N), cole o link e confira: o deck abre? Clique no deck e use as setas ← → (ou clique nas laterais) para passar os slides. Aperte **N** para ver as notas.
4. Se não abrir em aba anônima, **pare e me avise**: sem isso a entrega não vale.

## Passo 2 · Criar o repositório e subir os arquivos (15h10 a 15h22)
1. Entre em github.com (logado). Clique em **+** (canto superior direito), **New repository**.
2. Nome: `claude-lab-rjr-capital`. Marque **Public**. **Não** marque "Add a README file" (já temos o nosso). Clique **Create repository**.
3. Na tela do repositório vazio, clique em **uploading an existing file**.
4. Abra a pasta dos arquivos (a janela que abri no Explorador) e arraste para o GitHub **estes itens**:
   - `README.md`, `prompts.md`, `requirements.txt`
   - `apresentacao.html`, `notas_apresentador.md`
   - Código: `extrair_paginas.py`, `verificar_numeros.py`, `comparar.py`, `decomposicao_margem.py`, `grafico_trimestre.py`, `ebitda_por_tonelada.py`, `gerar_slides.py`, `rodar_tudo.py`
   - Dados: `metricas_gerdau.json`, `metricas_usiminas.json`, `dados_release_gerdau.json`, `dados_btg.json`
   - Documentos: `kpis_e_contexto_setor.md`, `drivers_setoriais.md`, `estimativa_margem_segmentos.md`, `tabela_comparativa.md`, `tabela_comparativa.csv`, `mensagens_slides.md`, `log_erros_claude.md`, `roteiro_video.md`, `entrega_formulario.md`, `passo_a_passo_entrega.md`
   - Pastas: `graficos` e `skills`
   - **NÃO suba:** a pasta `saida` e o arquivo `apresentacao_v2.html`.
5. Mensagem do commit: `Primeira versão da solução`. Clique **Commit changes**. (Se o GitHub reclamar do tamanho, suba em dois lotes: é até melhor, porque o guia pede commits pequenos.)
6. Abra o repositório numa janela anônima: o README aparece com os gráficos? Anote o endereço (`https://github.com/SEU-USUARIO/claude-lab-rjr-capital`).

## Passo 3 · Gravar o vídeo (15h22 a 15h37)
1. Abra o artefato em **tela cheia** (F11).
2. Leia o `roteiro_video.md` uma vez em voz alta (cerca de 2 minutos).
3. Grave a tela com a voz: Loom, OBS, gravador do sistema (Win+Alt+R) ou celular. **Máximo 2:00** (a banca só assiste até aí). Não edite; uma gravação simples vale mais.
4. Suba no **YouTube como "não listado"** ou no **Drive com "qualquer pessoa com o link"**. Copie o link e teste numa janela anônima.

## Passo 4 · Fechar o README (15h37 a 15h42)
1. No GitHub, abra `README.md` e clique no **lápis** (Edit).
2. Preencha a tabela **Equipe** (nome, curso/período, papel, LinkedIn ou GitHub de cada integrante).
3. Troque `[COLAR O LINK DO VÍDEO AQUI]` pelo link do vídeo. Confira que o link do artefato está lá.
4. **Commit changes**. (Se me mandar os nomes, eu escrevo a tabela pronta para colar.)
